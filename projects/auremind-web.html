AureMind Web

Overview

AureMind is an AI-powered note-taking and personal management web application designed to help students and professionals study and work more effectively through structured knowledge management and intelligent assistance. Built as a software engineering project, the platform combines traditional note organization with AI-driven features.

Project Brief

The project focuses on building a modern web-based productivity tool that enhances how users capture, organize, and retrieve knowledge. It integrates AI capabilities into the note-taking workflow, allowing users to not only store information but also interact with it dynamically. The system emphasizes usability, scalability, and efficient information retrieval.

What Was Built

A full-stack web application that allows users to create, edit, and organize notes in a structured environment. The platform incorporates AI features to assist users in generating notes, defining concepts, and quickly searching across their knowledge base. It supports a flexible note structure and interconnected knowledge systems.

Key Features

  • AI-powered note generation and summarization
  • Context-aware definitions for study concepts
  • User authentication and profile management
  • Task management and personal schedule organization
  • Clean and responsive web interface
  • Semantic search across all notes
  • Create, edit, and delete notes
  • Django-powered backend with SQLite database

Database Design

The schema was designed to 3rd Normal Form to eliminate redundancy. Key tables include Users, Notes, Tasks, and AuditLog. Foreign key constraints and transactions ensure data integrity across all operations.

Outcome

The project received positive feedback for its clean design, normalization approach, and transaction handling. Indexing on frequently queried columns was added as an extra improvement to boost query performance.
