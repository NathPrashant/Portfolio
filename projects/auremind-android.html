AureMind Android

Overview

AureMind Android is a secure, offline-first notes and task management mobile application built with Flutter. Designed for users who value privacy and reliability, it provides a fully functional productivity suite without requiring an account or internet connection.

Motivation

Many note-taking and task apps require cloud accounts, raising privacy concerns and making them inaccessible without internet. AureMind Android solves this by keeping all data local and encrypted, giving users complete control over their information.

Key Features

  • Encrypted local storage — all data stays on-device with no cloud dependency
  • Offline-first architecture — works fully without internet access
  • Calendar-based task management with due dates and priorities
  • Reminder and notification system for tasks and notes
  • PDF export for notes and task summaries
  • No account or sign-up required — zero friction to start
  • Clean, intuitive Flutter UI with smooth animations
  • SQLite database for fast local queries

Technical Highlights

The app is built with Flutter and Dart, targeting Android devices. All notes and tasks are stored in an encrypted SQLite database using local encryption libraries. The calendar view and reminder system are built on top of Flutter's native scheduling APIs, ensuring reliability across Android versions.

PDF export was implemented using a Flutter PDF generation library, allowing users to create shareable documents from their notes and task lists without any server-side processing.
