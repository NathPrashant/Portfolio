Packet Sentry

Overview

Packet Sentry provides a live view of your machine's network activity through a cross-platform desktop interface. The backend is written in Rust and uses pcap for packet capture, etherparse for protocol parsing, and sysinfo for process enumeration. The frontend is a React/TypeScript application served inside a Tauri webview.

Key Features

  • Network Graph: Captures raw packets on a selected network interface and plots upload/download throughput in real time.
  • Process Tracking: Lists all active system processes with their per-process bandwidth usage and exposes a kill action for any process directly from the UI.
  • Server Latency: Continuously pings Cloudflare DNS (1.1.1.1) and Google DNS (8.8.8.8) and renders rolling latency charts to give a quick baseline for network health.
  • Cross-Platform: Complete with pre-built installers for Windows (.exe, .msi) and Linux (.deb, .rpm).

Architecture

The application relies on Tauri 2 to bridge a high-performance Rust backend with a modern web frontend. By dropping down to Rust for system-level networking, the application can securely capture raw sockets (leveraging Npcap on Windows and elevated capabilities on Linux) while maintaining a lightweight GUI footprint through Vite and React 19.
