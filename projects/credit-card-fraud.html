Credit Card Fraud Detection

Overview

A machine learning system for detecting fraudulent credit card transactions using a Random Forest classifier. The project focuses on real-world feature engineering to improve model accuracy by extracting meaningful signals from raw transaction data including geolocation, time patterns, and merchant behaviour.

Problem

Credit card fraud causes significant financial losses globally each year. Detecting fraud in real-time requires models that can accurately distinguish legitimate transactions from fraudulent ones, even when fraudulent cases are extremely rare compared to normal transactions — a classic class imbalance problem.

Approach

The project uses a Random Forest classifier trained on engineered features derived from raw transaction records. Key feature engineering steps include:

  • Geolocation distance — computing distance between cardholder home location and merchant location
  • Time-based features — extracting hour of day, day of week, and transaction velocity patterns
  • Merchant category encoding — transforming categorical merchant data into model-friendly features
  • Transaction amount normalisation and outlier handling

Key Features

  • Random Forest classifier with tuned hyperparameters
  • Feature engineering pipeline on geolocation, time, and merchant data
  • Handling of class imbalance through resampling techniques
  • Evaluation using precision, recall, F1-score, and ROC-AUC
  • Full exploratory data analysis and visualizations in Jupyter Notebook

Results

The engineered features significantly improved model performance compared to using raw transaction data alone. The Random Forest classifier achieved strong recall on the minority (fraud) class while maintaining high precision, making it practical for real-world fraud detection where false negatives are costly.
